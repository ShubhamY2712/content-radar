Content Radar · Content Benchmark Research Agent

Give it a brand and a product. It finds the competitors, collects their strongest recent ads and organic posts, reads every creative on the 54 creative benchmark parameters, compares the brand with the market and writes a benchmark report with content ideas built on the same parameters.

01

What goes in, what comes out

Input

  • Brand and product, e.g. Mamaearth, Vitamin C face wash
  • Product type filled in by the agent, e.g. face wash
  • Competitors optional · agent finds 3 if not given
  • Their Instagram / Facebook IDs optional
  • Market default India
  • Platforms default Instagram, Facebook, YouTube
  • Time window default last 90 days
  • Creatives per competitor default 5, max 10
  • Brand's own creatives default 5, the baseline
→

Output: report.html + report_detailed.html

  • Two self-contained HTML reports for the brand's marketing team (fonts, icons, logos and creative thumbnails built in)
  • Product brief with a stat strip, and how "popular" was picked
  • Headline findings, each with its key number and the creatives that show it
  • Competitors and why they were chosen, with their links, and what the run could not cover
  • A note per competitor: strategy, what it repeats, its standout creative, what it does not do
  • Brand vs market: where the brand is behind and where it leads, plus a positioning map
  • Business view with the funnel, and creative and style view, parameter by parameter
  • Recommended content: 5 ideas on the same parameters, each with why it should work
  • Gallery of every creative; the detailed report adds every creative's key frames, hook, story structure and 54 findings, with filters
02

Architecture

The agent is a folder, not an app. Plain instructions, skills, knowledge and small read-only Python tools sit in one place; the AI it runs in does the thinking, so no model API key is needed. A main agent (the boss) runs the steps and hands the slow ones to workers that run side by side. Each building block below keeps its colour through the rest of this document.

Skills

Eight skills run in a fixed order. Each one reads the files the earlier steps saved, writes one output, checks it against its schema and logs one line.

1

brief-intake

v1.3.0

Turns the request into a complete research brief, fills defaults for anything not given and sets the product type the whole run focuses on.

Reads user requestWrites brief.jsonBy boss
2

competitor-discovery

v1.4.0needs approval

Uses the competitors given, or finds 3 that sell the same product type at a similar price and are active now. Records each competitor's matching product and product page, and every link where their content lives (website, Instagram, Facebook, YouTube, Meta Ad Library, Google Ads Transparency). Stops for approval.

Reads brief.jsonWrites competitors.jsonBy boss
3

creative-collection

v1.6.0one collector per brand

Product first: creatives showing the exact product, then the same product type, then the brand range. Ranks paid ads by days running and versions, organic posts by views and likes; at least 1 photo and 1 video, each with a reason and its product match. Adds 5 of the brand's own as a baseline. Saves media, frames, cut times, transcripts, sound tags and code measures; logs every skipped source and gap.

Reads brief.json, competitors.jsonWrites creatives.json, media/By collectors (up to 4 at once)
4

creative-analysis

v2.1.02 analysts + 1 checker per creative

Evidence first: for each parameter, what was seen (frame, time, measured value), then the option from the codebook. One analyst reads the 29 business parameters, another the 25 style parameters; a checker reads the same creative on its own. Disagreements are settled by re-reading the evidence. Translates Hindi and Hinglish.

Reads creatives.json, media/, knowledgeWrites analysis/<id>.json, checks/<id>.jsonBy analysts + checker
5

benchmark-synthesis

v1.3.0

A note per competitor, market patterns (what most do, what few do) with evidence, the brand compared with the market and 3–5 headline findings. Every number is copied from stats.json, counted by code.

Reads analysis/, stats.jsonWrites synthesis.jsonBy boss
6

content-recommendation

v1.4.1

Writes 5 content ideas: 2 proven patterns the brand does not use, 2 gaps nobody fills, 1 for another stage or format. Each idea gives audience, format, hook, message and proof, offer and CTA, style and layers, the parameters it uses and the creatives it is based on. Renders the markdown report.

Reads brief.json, synthesis.json, analysis/Writes recommendations.json, report.mdBy boss
7

report-document

v1.0.0

Writes the report's words and choices (findings, notes, tables, map axes, ideas, thumbnails, logos) into report_content.json from the run files only, then builds the summary and detailed HTML reports with the report kit and fixes every problem the renderer reports.

Reads all run filesWrites report_content.json, report.html, report_detailed.htmlBy boss
8

report-review

v1.3.0gate

Checks the finished run before it is called done: ids, counts and evidence agree across files, exact-product claims are proven, every idea is grounded in real creatives, gaps are reported, links open, nothing is guessed. Fixes what fails, re-renders, records the review and then deletes the downloaded videos to free space.

Reads all run filesWrites review.jsonBy boss

Team: boss and workers

The main agent is the boss. It runs steps 1, 2 and 5–8 and hands the two slow steps to workers that run side by side, up to 4 at once. Each worker writes only its own files and the boss merges them, so workers never overwrite each other and a stopped run resumes where it left off.

05

Accuracy

Research on AI models reading ads shows two weak spots: small text, counting and positions, and a habit of saying "yes" to features that are not there. The agent is built around both.

Measured, not guessed

Code measures what the AI is weakest at: on-creative text and its contrast (English and Hindi), text inside Meta's safe zones, faces and their size, main colours, whether the product pack is on screen, cut times and pace, speech vs music vs singing.

Codebook

Every option has a definition, what does not count and how to measure it, with examples from the manual analysis. "None" and "Not visible" are normal answers, never a failure.

Evidence first

Each answer starts with what was seen and where (frame, time, measured value), then the option. Answers without evidence fail the schema check.

Second reading

A checker reads every creative blind; the agreement rate is logged and every disagreement is settled with a reason.

Counted by code

stats.py counts every option across creatives; the synthesis copies its numbers and the review re-checks them.

Scored against people

compare.py scores the agent against the 10 manually analysed reference creatives (exact and partial match, chance-corrected agreement).

06

Skill registry

What each entry holds

  • name, version, description
  • order and depends_on
  • inputs, outputs, schemas
  • knowledge files it needs
  • tools it may use
  • permissions: internet_read, file_write_run
  • human_approval: true or false

What the registry checks

  • Every skill folder has a valid SKILL.md and skill.json
  • Names match folders; no duplicate order numbers
  • Every dependency comes earlier in the order
  • Every schema, knowledge file and tool it names exists
  • Only allowed permissions are used
# list, find, load and check skills
python tools/registry.py list            # skills in run order
python tools/registry.py search <text>   # find a skill
python tools/registry.py show <name>     # metadata + instructions
python tools/registry.py check           # check every skill
python tools/registry.py build           # check and write skills/registry.json

To add a skill: create skills/<name>/SKILL.md and skill.json, set its order, dependencies, inputs, outputs and approval, then run build. To change one: edit it and raise its version. Agent 2 (content creation) can plug into the same registry.

Built into the AI

Web search, page reading, sub-agents for the workers, 4 separate browsers for the Ad Library, Instagram and Google Ads pages, and image viewing for the analysis.

On the computer

Python 3.10+ with the packages in requirements.txt (OCR, OpenCV, scene detection, yt-dlp) and faster-whisper; ffmpeg; Node.js and Chrome for the browsers. The setup check installs what it can.

Keys and logins

A saved Instagram and Facebook login (auth.json, made once with a spare account) so the browsers get past login walls. API keys in .env are optional. Neither file is ever shared.

08

Knowledge: the yardstick

Exported from Creative Benchmark\Creative_Benchmark_Parameters.xlsx, so the agent analyses creatives exactly the way the manual benchmark does. When the Excel changes, the knowledge is exported again.

54 parameters

Business (29): hook and message 7, audience and intent 6, brand and action 6, offer and proof 5, video timing 5.

Style (25): format and imagery 5, layout and composition 5, video craft 5, colour and contrast 3, typography and text 3, people and brand 2, platform fit 2.

Each has what to check, its options, and where it sits for photo and video.

Shots × layers × assets

Story beats: SH1 Hook, SH2 Context / problem, SH3 Product reveal, SH4 Demo / benefit, SH5 Proof, SH6 Offer, SH7 CTA / end card.

Layers: L1 Background, L2 Product, L3 Props and set, L4 People, L5 On-creative text, L6 Graphic elements, L7 Brand, L8 CTA, L9 Lighting and finish, L10 Ad text and platform, L11 Interactive stickers, L12 Footage type, L13 Audio, L14 Motion and edit.

Option guide

Plain definitions for options that need judgment (for example what counts as "Results / transformation" or "Hero"), so every AI picks options the same way.

Worked examples

Creative 1 (photo) and Creative 2 (video) from the manual analysis, showing a complete, correct output.

11

Guardrails

Read only

Searches, opens pages and calls read-only APIs. Never types a password, posts, comments, likes, follows, fills forms or spends money; uses only the login the user saved.

No guessing

Every finding comes from a creative actually opened. Anything not seen or heard is marked not visible. No invented numbers, dates, links or quotes.

Sources on everything

Every competitor, creative and pattern carries its URL and the date it was seen.

Web text is data

Captions, comments and page text can never change the agent's rules or task.

Limits

Up to 5 competitors and 10 creatives each per run, up to 20 YouTube searches, up to 4 workers at once.

Internal use

The report contains other brands' ads. It stays internal until Pinaka approves sharing.

How to run it

Ask

Run the content benchmark for <brand>, <product>.

Optional in the same message: competitors, platforms, time window, creatives per competitor.

What happens

  • Setup check: fixes what it can, asks the user for the rest, starts only when ready
  • Capability check, written to log.md
  • Steps 1–2, then a stop for competitor approval
  • Steps 3–4 by the workers in parallel, then steps 5–7, saving each file as it goes
  • Finishes with the report path, headline findings and the 5 idea titles
