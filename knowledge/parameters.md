# Creative benchmark parameters

29 business and 25 style parameters. Each parameter is checked on a layer of the creative; for video also on a shot (story beat).

## Business – Hook and message

### B01 Hook message (Both)
- Check: The first line of text, first frame or first spoken words: what stops the scroll
- Options: free text
- Benchmark: Front-loaded and specific to the audience; works with sound off
- Photo: L5 On-creative text → Headline | L2 Product → Packshot | L4 People / characters → Face close-up
- Video: SH1 Hook · L5 On-creative text → Headline | SH1 Hook · L13 Audio → Voice-over, Dialogue | SH1 Hook · L4 People / characters → Face close-up

### B02 Hook type (Both)
- Check: The tactic the opener uses
- Options: Question; Bold claim; Problem call-out; Statistic; Curiosity gap; Pattern interrupt; Testimonial; Contrarian; Before / after; Demo / product in action; Offer-led; Persona call-out; Story open; Trend / pop-culture
- Benchmark: No single best type; compare by funnel stage
- Photo: L5 On-creative text → Headline | L2 Product → Packshot | L4 People / characters → Face close-up | L6 Graphic elements → Badge / sticker
- Video: SH1 Hook · L4 People / characters → Face close-up | SH1 Hook · L12 Footage type → A-roll (main / talking head), B-roll | SH1 Hook · L14 Motion and edit → Zoom / camera move, Speed effects (slow-mo, speed ramp) | SH1 Hook · L5 On-creative text → Headline | SH1 Hook · L13 Audio → Dialogue

### B03 Value proposition (Both)
- Check: The one benefit the viewer should remember
- Options: Price / savings; Quality; Convenience; Speed; Results / transformation; Safety / trust; Health; Status; Identity
- Benchmark: One benefit, stated early
- Photo: L5 On-creative text → Headline, Sub-headline, Tagline | L10 Ad text and platform → Long headline
- Video: SH4 Demo / benefit · L5 On-creative text → Headline | SH4 Demo / benefit · L13 Audio → Voice-over

### B04 Single clear message (Both)
- Check: Can the main message be restated in one sentence
- Options: Clear and early; Clear but buried; Several competing messages
- Benchmark: One message per ad
- Photo: L5 On-creative text → Headline | L10 Ad text and platform → Primary text / caption, Headline field
- Video: All beats (SH1–SH7) · L5 On-creative text → Headline, Captions / subtitles | All beats (SH1–SH7) · L13 Audio → Voice-over

### B05 Supporting facts (Both)
- Check: Evidence that backs the message
- Options: Problem; Feature; Benefit; Spec / ingredient; How it works; Comparison; Proof point
- Benchmark: At least one benefit plus one feature or mechanism
- Photo: L5 On-creative text → Benefit points, Stats / numbers | L6 Graphic elements → Icons, Chart / data graphic, Arrows / callouts
- Video: SH4 Demo / benefit · L5 On-creative text → Benefit points, Stats / numbers | SH4 Demo / benefit · L6 Graphic elements → Arrows / callouts | SH4 Demo / benefit · L13 Audio → Voice-over

### B06 Problem–solution clarity (Both)
- Check: Is a problem shown and the product presented as the fix
- Options: Clear; Partial; Absent
- Benchmark: –
- Photo: L5 On-creative text → Headline, Sub-headline | L6 Graphic elements → Before–after split | L2 Product → Product in use
- Video: SH2 Context / problem · L4 People / characters → Model / talent, Creator (UGC) | SH4 Demo / benefit · L2 Product → Product in use | SH4 Demo / benefit · L6 Graphic elements → Before–after split | SH4 Demo / benefit · L14 Motion and edit → Split screen / PIP | SH4 Demo / benefit · L13 Audio → Voice-over

### B07 Product shown and role (Both)
- Check: How visible and central the product is
- Options: Hero; Visible, secondary; In use / demo; Incidental; Not shown
- Benchmark: Awareness: brand-led; action: product is the ad
- Photo: L2 Product → Packshot, Product in use, Close-up / texture | L3 Props and set → Ingredients
- Video: SH3 Product reveal · L2 Product → Packshot, Product in use | SH4 Demo / benefit · L3 Props and set → Ingredients | SH4 Demo / benefit · L12 Footage type → A-roll (main / talking head), B-roll

## Business – Audience and intent

### B09 Awareness stage (Both)
- Check: How much the ad assumes the viewer already knows
- Options: Unaware; Problem-aware; Solution-aware; Product-aware; Most aware
- Benchmark: Hard offers to cold audiences are a mismatch

### B10 Funnel stage (Both)

- Options: Awareness; Consideration; Action; Full funnel
- Benchmark: Compare creatives only within the same stage

### B11 Appeal and emotion (Both)

- Options: Rational; Emotional – humour; Emotional – aspiration; Emotional – FOMO; Emotional – relief; Emotional – belonging; Emotional – surprise; Emotional – fear; Emotional – nostalgia; Mixed

- Video: SH2 Context / problem · L4 People / characters → Face close-up | SH4 Demo / benefit · L13 Audio → Music | SH4 Demo / benefit · L9 Lighting and finish → Colour grade / filter

### B12 Occasion, season or trend (Both)
- Check: Timely context the ad rides on
- Options: Festival / holiday; Sale event; Launch; Season; Pop-culture trend; Evergreen
- Benchmark: –
- Photo: L1 Background → Scene / location | L3 Props and set → Lifestyle props, Florals / natural elements | L6 Graphic elements → Badge / sticker, Emoji / GIF | L5 On-creative text → Headline
- Video: SH1 Hook · L1 Background → Scene / location | SH1 Hook · L3 Props and set → Lifestyle props | SH1 Hook · L13 Audio → Music (trending) | SH1 Hook · L14 Motion and edit → AR effects / filters | SH1 Hook · L5 On-creative text → Headline

### B13 Language and localisation (Both)
- Check: Language of copy and voice, and local fit
- Options: English; Hindi; Hinglish; Regional language; Multi-language
- Benchmark: Match the language of the target audience
- Photo: L5 On-creative text → All text | L10 Ad text and platform → Primary text / caption
- Video: All beats (SH1–SH7) · L5 On-creative text → All text, Captions / subtitles | All beats (SH1–SH7) · L13 Audio → Voice-over, Dialogue
